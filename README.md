# Достигатор — мобильное приложение

Приложение для резидентов бизнес-клуба и экосистемы «Достигатор» (Грозный). Оператор — АНО «Достигатор Медиа». Открытой регистрации нет: учётные записи выдаёт организатор клуба.

Один код на Flutter 3.44.1 для iOS, Android и веба. Bundle ID — `org.dostigator.dostigator`.

## Что внутри

- **Пульс** — фокус недели, прогресс цели, еженедельный чек-ин.
- **Планер** — цели с шагами, привычки, задачи и план по дням.
- **Группа** — мастермайнд-группа, встречи и посещаемость.
- **События** — афиша, календарь, прошедшие мероприятия, запись и QR-билет.
- **Клуб** — разделы «Бизнес-клуб» и «Экосистема», карточки резидентов, карта резидента с QR и привилегиями партнёров, база знаний.
- **Профиль** — фото, бизнес-профиль, приватность, светлая и тёмная тема, удаление аккаунта.

Рекламы, покупок, аналитики и сторонних SDK нет.

## Об этой копии

Это открытая копия исходного кода. Из неё убрано всё, что не должно быть в общем доступе:

- в тестах настоящие имена, компании и телефоны заменены вымышленными;
- адрес боевого сервера заменён заглушкой — его задают при сборке;
- ключи подписи и настройки окружения в репозиторий не входят;
- файлы фирменного шрифта Stolzl не включены: у шрифта коммерческая лицензия. Перед сборкой положите `stolzl_light.otf`, `stolzl_regular.otf`, `stolzl_medium.otf` и `stolzl_bold.otf` в `assets/fonts/`.

## Сборка

```bash
flutter pub get
flutter test
flutter build ipa --release --dart-define=API_BASE_URL=https://<адрес сервера>
```

Сборка iOS в облаке описана в `codemagic.yaml`.
